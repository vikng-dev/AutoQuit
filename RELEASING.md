# Releasing AutoQuit

Signed + notarized macOS app, distributed via GitHub Releases and a Homebrew tap.

## Commit messages

Release notes are auto-generated by `git-cliff` from commits between tags, so
write [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` — new user-facing capability → **Features**
- `fix:` — bug fix → **Bug fixes**
- `perf:` — speed/memory improvement → **Performance**
- `refactor:` — reshape without behavior change → **Refactor**
- `docs:` — README / inline docs → **Documentation**
- `test:` — test-only change → **Tests**
- `build:` — build system / release scripts → **Build**
- `ci:` — CI-only change → **CI**
- `chore:` — routine maintenance, dep bumps → _omitted from notes_

Append `!` for a breaking change: `feat!: drop macOS 12`. Commits without a
prefix bucket under "Other" — try not to.

Preview the next release's notes:

```bash
git-cliff --tag v1.2.3 --unreleased
```

## Versioning

`MARKETING_VERSION` follows SemVer (`MAJOR.MINOR.PATCH`).
`CURRENT_PROJECT_VERSION` (the build number) is auto-incremented on every
release — never decrement or reuse it (Sparkle and the App Store use it to
detect "is this newer?").

## Cut a release

```bash
just release 1.2.3
```

End-to-end: pre-flight checks → universal build → sign + notarize DMG →
git-cliff notes → bump versions in `project.yml`, commit, tag (`v1.2.3`),
push → `gh release create` with the DMG + sha256 + notes.

Then bump the Homebrew cask:

```bash
SKIP_BUILD=1 just release-homebrew 1.2.3
```

This runs `brew bump-cask-pr` against `vikng-dev/homebrew-tap`, opening a
PR with the new `version` and DMG `sha256`. Merge it.

Artifacts land in `dist/` (gitignored).

## Overrides

```bash
SKIP_PUSH=1 just release 1.2.3                  # dry run: build + tag locally
SKIP_GITHUB_RELEASE=1 just release 1.2.3        # everything except gh release create
NOTARYTOOL_PROFILE=my-profile just release 1.2.3
DEVELOPER_ID_APPLICATION="Developer ID Application: …" just release 1.2.3
```

If a release fails after the commit/tag/push but before `gh release create`,
re-publish manually:

```bash
gh release create v1.2.3 dist/AutoQuit-v1.2.3.dmg dist/AutoQuit-v1.2.3.dmg.sha256 \
  --repo vikng-dev/AutoQuit \
  --title "AutoQuit v1.2.3" \
  --notes-file dist/release-notes-v1.2.3.md
```
